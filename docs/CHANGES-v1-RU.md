# Изменения в unofficial v1 (первый публичный релиз)

Для кого: пользователи порта и разработчики, которым нужно знать, что изменилось после архива v5 (2026-10-30) и почему.
Подробности с md5 и журналами проверок: `docs/ЧТО_НОВОГО-v6.txt`, `-v7.txt`, `-v8.txt`.

| | v5 (2026-10-30) | unofficial v1 (2026-11-10) |
|---|---|---|
| Ядро | 7.1.2 #430 | 7.1.13 + правки q6voice, панели и ath11k (`kernel/`) |
| Дерево устройств | в стиле downstream | DTB в стиле апстрима + локальные узлы, включён RTC |
| dtbo | не менялся | `dtbo-frag` пишет установщик |
| Образ | снимок одного телефона | чистый образ: без личных данных, ключей и закрытых прошивок |
| Zip | `postmarketos-lomiri-m52xq-mainline-v5.zip` | `postmarketos-lomiri-m52xq-mainline-v1-UNOFFICIAL.zip`, md5 `eba0bbd593c733a6f49ccc6ab4d63ac2` |

Нужна чистая установка (Format Data).

## Установщик и образ
- **В zip нет закрытых прошивок.** DSP, zap-шейдер GPU, IPA, Venus, модем, прошивка Bluetooth, конфиги датчиков и адрес
  Bluetooth берутся с разделов самого телефона при установке (установщик порта postmarketOS Plasma).
- Образ релиза — снимок настроенного телефона (`image/build-v8-image.sh`) без данных /home, сетей Wi-Fi, пар Bluetooth, выбора SIM,
  журналов, ключей SSH, machine-id; пароль 1111; проверен на личные значения.
- Часовой пояс из мастера применяется: политика systemd-timedated требует пароль администратора, Lomiri спрашивает без него, и
  polkit молча отказывал (`etc/polkit-1/rules.d/50-m52xq-timedate.rules`).

## Ядро
- Звонки: переключение громкая/разговорный без новых голосовых сессий (аудио-DSP больше не падает).
- Экран: нет вспышки при пробуждениях по сети (панель спит, пока яркость 0).
- Выключенный Wi-Fi действительно спит (энергосбережение ath11k при выключенном радио).
- Включён RTC: будильник будит телефон из сна.

## Звонки, SIM и мобильные данные
- Входящий во сне: экран включается, после звонка возвращается экран блокировки. Раньше звонилка оставалась «закреплённой» над
  экраном блокировки: свайпы с краёв, шторка и цифры не работали до блокировки и разблокировки (`Shell.qml`).
- Быстрые нажатия на номеронабирателе больше не теряются (Kirigami ColumnView запускал пустую анимацию на каждом касании: патч под
  6.31, `build/v7/kirigami`).
- Менеджер SIM: питание SIM-карт, режим, SIM мобильных данных и переключатель мобильных данных; кнопки SIM данных серые, пока данные
  выключены; переключатель синхронен со шторкой в обе стороны; после смены SIM или режима данные поднимаются на новой SIM.
- Шторка: переключатель мобильных данных больше не дёргается каждые несколько секунд.
- Исправлены падение ModemManager при подключении данных (use-after-free) и падение KPeople (база в двух потоках).

## Telegram Desktop
- Wi-Fi держится во сне: хук сна взводил WoWLAN по неверному пути к `iw`, и NetworkManager рвал Wi-Fi перед каждым сном.
- Пробуждение по Wi-Fi при запущенном Telegram держит телефон 45 с (после долгого сна ему нужно столько, чтобы переподключиться).
- Экран включается, когда во сне звонит Telegram; во время звонка телефон не засыпает и не гасит экран.
- Звук разговора переходит в разговорный динамик (играющий поток переоткрывается; на 7.1.13 одна смена маршрута его не переносила).

## GPS
- После загрузки скачиваются и загружаются в модем данные XTRA (`m52xq-gps-xtra` + таймер): раньше холодный старт не давал фикса даже у окна.
- NMEA от ModemManager передаётся в gpsd по порядку (gpsd через раз сообщал «нет фикса»).
- lomiri-location-service с gpsd ≥ 3.20 не отдавал позицию вообще (проверял устаревшее поле высоты): прослойка LD_PRELOAD
  `m52xq-gps-alt` (`build/v7/gps`).

## Камера
- Цифровой зум до 4x в источнике камеры (видоискатель, фото, видео), шкала зума помещается в альбомной ориентации.
- Megapixels адаптирован под Lomiri (масштаб, кнопки в портретной и альбомной).

## Известные проблемы
- Изредка прошивка Wi-Fi падает в долгом сне; Wi-Fi возвращает перезагрузка.
- После смены сети значок Wi-Fi может пропасть при подключённом Wi-Fi; помогает перезагрузка.
- `apk upgrade` заменит пропатченные пакеты порта; полное обновление не запускайте.
