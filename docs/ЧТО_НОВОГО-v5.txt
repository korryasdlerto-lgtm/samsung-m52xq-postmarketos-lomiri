lomiri v5
postmarketOS mainline + Lomiri (без Plasma) для Samsung Galaxy M52 5G (m52xq) — архив lomiri v5 (2026-10-30)

Образ системы тот же, что в v3/v4 (boot v241 + vendor_boot v238 + рутфс v3). Все правки ставятся установщиком как файлы поверх образа
(mainline-extras/rootfs-files = инъекции v4 + v5), поэтому архив по размеру как v4. Данные /data при прошивке стираются.

Новое по сравнению с v4:
- Заставка загрузки: логотип postmarketOS, «postmarketOS / Lomiri», «ubuntu touch style», точки; яркость заставки нормальная
  (systemd-backlight замаскирован, яркостью занимается m52xq-powerkey).
- Название системы: «postmarketOS Lomiri» вместо «Nura» (Настройки → О телефоне, мастер приветствия, консоль).
- Камера Lomiri: видео через аппаратный Venus (1080p, 4K ≤ 24 к/с; основная и фронтальная), звук AAC; квадрат фокуса по касанию и
  программный автофокус основной камеры; список мегапикселей помещается на экране; 16 Мп = 4608×3456 (без шахматки); в меню видео
  всегда 720p / 1080p / 2160p.
- Wi-Fi остаётся включённым во сне и будит телефон по пакету (WoWLAN): свой ath11k_ahb.ko (повтор выхода из сна, ожидание 5 с),
  флаги WoW 0x20 (служба m52xq-wow-params), скрипт, выгружавший Wi-Fi на сон, отключён. Проверено: десятки циклов сна/пробуждения,
  5-минутный сон, пробуждение кнопкой — без падения прошивки WPSS. Известно: «чужой» пинг без записи в ARP-кэше может не разбудить.
- Подкачка zram включена (7,4 ГБ, zstd): запись 4K больше не убивает камеру/клавиатуру по нехватке памяти.
- Pure Maps: сервер карт osmscout-server стартует (исправлен шаблон valhalla); для карты нужен онлайн-профиль.
- Геолокация: служба ждёт порт gpsd (раньше «GPSD Error» каждую секунду). Спутники в помещении не ловятся.
- Исправлено из в4: службы m52xq-osk-bridge, m52xq-messaging-bridge, m52xq-ringtone, m52xq-sim-slots теперь включены после установки
  (установщик возвращает симлинки в *.wants), в4-инъекции обновлены (m52xq-powerkey, m52xq-reboot-recovery и меню питания).

Известные проблемы v5: камера держит Venus после остановки записи (родной плеер не открывает 4K, пока камера открыта); 4K с фронтальной
≈17 к/с; пробуждение подсветки ложным нажатием кнопки при пробуждении пакетом (редко); GPS без фикса в помещении.
